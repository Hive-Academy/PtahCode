# Pack: content

## Discipline
Content work produces documentation, articles or other written material. Every claim must trace to a source. The output is text, so the work has a specification step and an editorial review.

## Skeleton mapping
- clarify: the pre-flight questions that fix the audience, the topic and the format. No phase file.
- plan: the `plan` phase.
- do: the `docs` phase (content specification) and the `implement` phase (write the documentation).
- check: the `review` phase.
- deliver: the `completion` phase.

## Phase flow
- plan: define the outline, the audience and the sources.
- docs: write the content specification.
- implement: write the documentation from the specification.
- review: check each claim against its source and check the style.
- completion: publish or hand over the content, then close the task.
