# @ptah-extension/ui

Shared UI components for the renderer: overlays, selection, native (CDK-free, Floating UI based) components, motion and surfaces (see `src/index.ts`). Tagged `scope:webview`, `type:ui`.

```bash
npm run verify -- -p ui
```

Design system plan: read `.ptah/specs/TASK_2026_924_8ac1/design-system-epic.md` before you add or change a shared component. It gives the two levels (primitives and composites), the six steps of a family, the enforcement rules and the status of each family.
