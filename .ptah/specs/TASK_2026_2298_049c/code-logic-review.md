## Five logic questions

1. **Silent failure:** History cleanup and SDK displacement can lose a report after a pending acknowledgement (3, 4).
2. **Unexpected user action:** Handing off a parent during a drain can expose later reports to the former owner (1).
3. **Wrong answer from input:** A chat with a cwd-inferred child SDK alias gains child attribution, and overlapping identical reports can both be accepted (2, 6).
4. **Dependency failure:** A rejected send restores its suffix when the record exists, but the current caller can bypass it. SDK displacement can also resolve the send against a stale queue (3–5).
5. **Unspecified behavior:** Queue cleanup on retention and rollback, host listener lifetime, and simultaneous admissions need explicit handling (3, 5, 10).
