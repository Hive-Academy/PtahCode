## Proposed Removals — APPROVED

User approval: 2026-11-24, `decisions.md` D5. Each removed capability keeps its named
replacement; no other capability is removed.

- APPROVED - Pre-select ALL recommendations (`analyze/analyze-skills.page.ts:250-257`).
  Replacement: install-verdict pre-selection; nothing pre-selected when no valid install
  verdict exists. Every recommended skill stays visible and selectable by hand.
- APPROVED - One project skill draft form rendered automatically per unmatched `framework` or
  `pattern` item (`proposal/unmatched-stack-list.component.html:29-31`). Replacement: build
  verdicts, each with a create option. The per-item "Search for <name>" action, the create flow,
  and a draft opened on request for any item stay.
- APPROVED - Fixed-template draft content (`analyze/project-skill-draft.component.ts:43-45`).
  Replacement: generated skill content for a `build` verdict, editable before
  `harness:create-skill`. When generation fails, the draft still opens with the item's name and
  evidence for manual writing.
