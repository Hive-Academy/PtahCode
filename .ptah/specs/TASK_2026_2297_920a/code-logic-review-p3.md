1. **Where can failure look like success?** Findings 2, 3 and 8 cover stale receipts, persisted but unreadable bodies, and uncertainty reported as queued.
2. **What user action produces unexpected behavior?** Reopening a parent in a new tab or repeating a report after reparenting can leave the current parent without the report. See findings 2 and 5.

5. **What implicit case needs a contract?** A verified binding restored after startup needs to wake a pending receipt, and a concurrent reparent needs a defined admission and dispatch ordering. See findings 1 and 6.
