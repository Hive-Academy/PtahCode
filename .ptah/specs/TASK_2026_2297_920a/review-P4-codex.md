# P4 independent review

**Verdict — changes requested.** Budget pauses can happen without informing the parent or emitting the manager event. The host dispatch hold has live entry points that bypass it, and a repeat pause can strand accepted receipts after normal settlement.

Paths below are relative to `libs/backend/cli-agent-runtime/src/lib/` unless prefixed with `libs/`.

## P1 — High

1. **Budget notices never reach the parent or the manager event.** `cli-agents/lane-budget-telemetry.ts:130` claims the deduplication key before calling its injected handlers. Both handlers call `publishLaneNotice` (`cli-agents/agent-process-manager.service.ts:521`), which claims the same key and returns before emitting or notifying (`:633`, `:642`, `:647`). Weighted, duration and telemetry notices can appear in status and close the gate while the parent hears nothing, including on an unverified CLI. Make one layer own state and deduplication, and add manager-level assertions for one event and one parent delivery per budget phase.

2. **Ordinary immediate messages can steer a paused lane into new work.** `cli-agents/agent-message-router.service.ts:193` forwards any explicit steer before checking pause. At `:213` and `:219`, any `now` message can also steer a paused lane with that capability. This is a functional bypass on a steer-capable CLI without a verified tool gate. Hold ordinary caller messages in the receipt queue, including `now` and explicit steer, and reserve paused steering for a trusted host-generated handoff request.

3. **Resuming by session ID can bypass the live pause.** `cli-agents/agent-process-manager.service.ts:1078` finds the tracked lane but `:1091` passes only a ledger-derived budget notice to the resume gate. A running lane paused by repeat or inactivity can still pass the ordinary resume decision and start another SDK handle for its session (`:879`, `:883`; registry-backed entry at `:1218`). The new handle has an independent pause probe keyed to its new agent ID (`:1431`). Refuse a resume or automatic fresh fallback targeting a live paused owner, with its Ptah reason, and recheck ownership immediately before launch. Test repeat and inactivity through both spawn entry points.

4. **Repeat pause strands queued receipts after the lane returns.** `cli-agents/agent-process-manager.service.ts:3901` records normal completion and schedules idle release. The subsequent queue flush (`:3938`) exits on the retained pause (`cli-agents/agent-message-router.service.ts:398`). Repeat admission clears only after a continuation has already been admitted (`cli-agents/agent-process-manager.service.ts:3188`). Idle release eventually discards those entries with `subprocess_released` (`:3720`–`:3726`). Snapshot the notice for the completion envelope, clear the settled turn's active repeat hold, and drain the queue if the lifetime ledger permits. Preserve receipts with an actionable hold if the session remains over budget. Extend `cli-agents/agent-process-manager.guard.spec.ts:273` through settlement and dispatch, since it currently stops at checking the live queue.

5. **Budget refusal can switch a named Claude lane to ambient.** The new paused-budget branch returns `fresh` before account resolution (`cli-agents/lane-resume-gate.ts:126`–`:153`). The manager automatically builds and launches a fresh handoff, and its named-profile selection depends on the gate returning `accountReference` (`cli-agents/agent-process-manager.service.ts:879`–`:899`, `:947`–`:970`). An omitted selection on a resume request also skips workspace selection (`:994`–`:996`). Validate the original account before any automatic fresh handoff and carry its reference into the new admission, or return a typed refusal without launching. Cover an over-ceiling named Claude session with omitted selection.

## P2 — Medium

6. **The budget ask can be skipped, and a valid telemetry sample can clear a live telemetry pause.** The coordinator returns only the current admission (`cli-agents/agent-budget-coordinator.ts:119`–`:130`). Telemetry dispatch takes the pause branch before sending an ask, so a weighted sample that jumps from below warning to past 2× skips the handoff request (`cli-agents/lane-budget-telemetry.ts:123`–`:139`). This also drops the earlier projected warning required by batch 14. A subsequent valid sample after three missing samples can yield `running` and clear an already-issued telemetry notice in the same tracked turn (`libs/shared/src/lib/utils/agent-budget-policy.ts:265`, `cli-agents/lane-budget-telemetry.ts:124`–`:128`). Preserve projected warning, publish both phases on a direct crossing in order, and keep telemetry admission latched independently of the resettable miss counter. Test a single large turn and recovery telemetry after a pause.

7. **Continuation can use stale budget settings and the router checks pause before asynchronous dispatch.** The settings listener skips settled lanes with no previous budget notice (`cli-agents/agent-process-manager.service.ts:534`–`:537`). Lowering the limit can put such a ledger over 2× while live continuation still admits against the old settings (`:3135`–`:3138`). The queue flush checks admission before awaiting its journal write (`cli-agents/agent-message-router.service.ts:398`, `:437`–`:439`), then treats a late rejection as a failed receipt (`:448`–`:455`). Apply current settings to idle ledgers and recheck the host hold after journal and account awaits, immediately before turn start. A late hold should re-park the same receipt. Test a settings change during a pending dispatch and after an unpaused turn settles.

8. **Inactivity timing can publish a false pause and leave timers active during teardown.** Output only clears admission in the throttled flush (`cli-agents/agent-process-manager.service.ts:3506`–`:3523`), so already-buffered output can lose the race against either deadline. The two timers use raw delays (`:3556`–`:3568`), and 2W can exceed Node’s timer maximum even when W fits. That pause then fires almost immediately. Stop clears both only after awaiting kill and file cleanup (`:3340`–`:3345`). Dispose starts releasing running handles before clearing the watches (`:3381`–`:3402`), and the callback only checks running status and `hasExited` (`:3590`). Record real activity at ingestion, check elapsed silence against the deadline at callback time, schedule long waits in bounded chunks, and invalidate both watches before teardown yields. Add tests for output immediately before 2W, a large W, and delayed teardown.

9. **A failed parent enqueue has no reliable retry.** `cli-agents/lane-completion-notifier.service.ts:462`–`:495` forgets its key on failure, but the manager has already claimed the announcement and never retries its fulfilled `failed` result (`cli-agents/agent-process-manager.service.ts:633`, `:646`–`:653`). Latched notices generally do not cross again, so the only copy can be a log. Keep a retryable outbox entry under the same delivery key until the durable enqueue or live fallback succeeds. Test a transient enqueue refusal followed by parent activation.

10. **Parent copy can give the wrong cause or state.** The unavailable-gate fallback replaces the actual reason with `tool-gate-unavailable` (`cli-agents/agent-process-manager.service.ts:680`–`:688`), and repeat notices use `ptah-watchdog` where the brief assigns `ptah-budget` (`:2113`–`:2116`). A normal completion can still claim the next turn stops the lane (`cli-agents/lane-completion-envelope.ts:90`–`:91`) or that the execution remains live (`:116`–`:117`, `libs/shared/src/lib/types/agent-action.types.ts:209`–`:210`). Keep the trigger and actor in the pause text, append the unsupported-gate scope, and format the completion notice in past tense with accurate resume guidance. Update envelope assertions for both an undelivered ask and a completed pause.

11. **A queued inactivity ask can outlive the inactivity it describes.** The fallback can put an ask into the adapter mailbox or splice it directly into a caller message (`cli-agents/agent-process-manager.service.ts:577`–`:586`), or store it later in the shared warning slot (`:603`–`:606`). Real output clears only the notice (`:3521`), and the next send still consumes the stale warning (`:2990`–`:2991`). Track pending asks with their source and activity generation, and attach them only at dispatch while still current. Tell the parent when the active turn could not receive the ask, as specified in the plan. Test failed steering followed by real output and then a caller message.
