## Cell rules

- User values take precedence over local values, then shipped seed, then unknown. Unknown at a higher layer does not mask a lower value. Staleness is recomputed on merge: `capability-matrix.store.ts:516`.
- No installed/configured CLI filter applies to this RPC: profiles are the union of those three matrix layers (`capability-matrix.store.ts:533`). Saved historical models remain visible without installed executors or credentials. Agent detection/routing eligibility is a separate concern.
- Family mapping is the CLI name for system CLIs, provider ID for Ptah CLI, otherwise `ptah-cli:<id>`/`ptah-cli`: `libs/shared/src/lib/utils/lane-family.ts:32`. Subagents use family `claude`. Local cells use stored family/model literally; `lane-default` and `auto` map to family profile `*`: `libs/backend/lane-routing/src/lib/matrix/local-derivation.ts:136` and 168. Family fallback is for routing lookup, not inventing extra table rows.
- Records deduplicate by run ID. A non-null task kind, nonblank family/model, and finite end time within 90 days are required. One contributing run is sufficient; there is no minimum of 5 or 10 samples. `local-derivation.ts:70`, 136, 179, 285.
- Delivery success rate is delivered / (delivered + no-deliverable + failed). Capacity failures (`usage-limit`, `auth`, `timeout`) do not contribute delivery failures. Review rate uses approvals over approvals + rejections + unresolved revise runs; unresolved revisions count against the review rate. Unverified delivery contributes no delivery rate. Each available rate is blended as `round(100 * (successes + 10 * prior / 100) / (samples + 10))`. Prior is the exact seed cell or 50; if both rates exist their blended mean is rounded. Sample count counts unique contributing runs; `asOf` is their newest end time. See `local-derivation.ts:273` and 308.
- Stale means strictly older than 180 days (`routing-constants.ts:165`), while history is restricted to 90 days (line 177). Therefore recent local data cannot legitimately yield stale cells. Aged user assessments supply the two stale examples.
- Shipped seed has only `z-ai / glm-5 / implement` with score 80 and benchmark date 2026-02-17; all its other task kinds are unknown. See `matrix/seed-matrix.ts:58`. This explains the previous single populated family/model.
