# Batch 8 independent review

## Findings

1. **Medium — variable badge text can clip without an ellipsis.** `libs/frontend/tasks-ui/src/lib/components/board/task-card.component.ts:389`, `board/task-list.component.ts:195`, `libs/frontend/skill-synthesis-ui/src/lib/components/clones/scorecard-badge.component.ts:34`, `clones/scorecard-detail.component.ts:123`, and `libs/frontend/tasks-ui/src/lib/components/detail/task-run-placeholder.component.ts:32` render interpolated text directly in an inline-flex `ptahBadge`. The owner CSS explicitly requires a direct `.ptah-badge-text` child for ellipsis. This is most consequential for task type and scorecard labels; the stage, document state, executor and gateway platform badges already use the child correctly. **Fix:** wrap variable label text in `<span class="ptah-badge-text">…</span>` for each converted badge; keep icons outside the text child.

2. **Medium — large estimate emphasis changes.** `libs/frontend/tasks-ui/src/lib/components/board/task-card.component.ts:397` and `board/task-list.component.ts:398` map `L` and `XL` from `badge-neutral` (a filled neutral badge) to `tone="neutral"` with `appearance="soft"` (the owner CSS uses only a 10% tint). The old estimate mapping explicitly uses a filled badge to distinguish large sizes from outlined smaller ones. The neutral meaning survives, but the filled visual weight does not. **Fix:** preserve the filled treatment with an owner-supported appearance if available; otherwise leave these two estimate badges raw until the owner has an equivalent recipe.

3. **Low — the card spec no longer checks all badges.** `libs/frontend/tasks-ui/src/lib/components/board/task-card.component.spec.ts:227` changes the “exactly one badge” query from `.badge` to `[data-ptah-badge]`. The card still has raw label badges, so this assertion can pass while additional raw badges render. **Fix:** if the test intends to count all visible badges, query both selectors (and keep the old square exclusion); otherwise rename the test to say it counts owner badges only.
