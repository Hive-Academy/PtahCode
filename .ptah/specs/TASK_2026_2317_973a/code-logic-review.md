## Findings

1. **Serious — The added metadata can force a budget overflow and break the served JSON contract.** At `libs/backend/workspace-intelligence/src/ast/ast-result-format.ts:169` and `:198`, an all-rows-cut candidate still carries the full per-list name summary. If that candidate fails `fits`, the formatter can return it at `:185` without reducing the optional metadata. An in-memory comparison against HEAD using the current hint and production token counter produced 114 tokens with HEAD and 4,600 with the changed formatter for one cut class with six valid, 250-character Unicode method identifiers. The formatter target is 1,800 tokens and the hard limit is 2,000. The formatter output itself parses. In the dispatch path the over-budget text enters the generic reduction and spool-trailer path, so the returned text is no longer guaranteed to parse as the promised JSON. [Formatter and budget call](../../../libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-core/ast-analyze-output.ts#L122) · [Generic output budget](../../../libs/backend/tool-output-reducers/src/lib/output-budget/apply-output-budget.ts#L155)
2. **Moderate — A reported method name can fail the lookup the hint recommends.** At `libs/backend/workspace-intelligence/src/ast/ast-result-format.ts:102` the formatter qualifies with the immediate class only. A cut nested class yields `Inner.run`, while navigation indexes that method as `Outer.Inner.run`. `ptah_read_symbol` matches the simple name or the full qualification exactly, so copying `Inner.run` fails. The hint at `libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-core/ast-analyze-output.ts:38` also says “whole class” without mentioning the line and character limits. Its read suggestion applies to classes, functions and methods, while the same hint can accompany cut export names for interfaces, types or constants. [Qualification](../../../libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-core/nav/nav-symbols.ts#L96) · [Lookup and limits](../../../libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-core/nav/read-symbol.ts#L157)
3. **Moderate — The count includes non-records and the class-specific metadata applies to any list.** At `libs/backend/workspace-intelligence/src/ast/ast-result-format.ts:71`, `:95` and `:127`, the naming pass skips unnamed owners and members, but the count sums raw array lengths, including `null`, scalars and holes. A cut `{name: 'A', members: [null, 4, {}, {name: 'x'}]}` reports `omittedMembers: 4` and `A,A.x` with no cap marker. Counted unnamed member records can legitimately lack a usable name, but non-record entries are counted as methods, and the hint leaves the reason for unlisted members unspecified. The same code produces `I,I.run` for a cut interface with a `members` array, and would do so for functions and imports with that field. Current MCP shaping attaches `members` only to classes, so these malformed or non-class cases affect the generic formatter contract. [Current shape](../../../libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-core/ast-analyze-output.ts#L74)
4. **Minor — The character cap has two boundary errors and the spec allows both.** At `libs/backend/workspace-intelligence/src/ast/ast-result-format.ts:109-120`, charging a comma for the first name rejects a single 1,800-character name that would fit. A 1,799-character name followed by another candidate yields 1,801 characters after appending `,…`. The 150-name check allows up to 150 actual names plus the marker, which is consistent when the marker is excluded from the name count. The character-case fixture reaches the character cap first and permits 1,810 characters, so it neither enforces the 1,800 limit nor independently exercises the 150-name cap. [Cap assertions](../../../libs/backend/workspace-intelligence/src/ast/ast-result-format.spec.ts#L269)
5. **Minor — The fixture can still inherit a linked worktree via the temp directory.** At `libs/backend/cli-agent-runtime/src/lib/cli-agents/agent-process-manager.account-binding.spec.ts:75-79`, `tmpdir()` ordinarily gives an external directory, but CI can point its temp directory inside the checkout. Setting `TMPDIR` to this worktree reproduced the main-checkout resolution, which reintroduces the extra read in the ambient-default assertion at `:783`. The portability improvement works with conventional POSIX and Windows temp paths.
