A repeated pattern is only a candidate: copy the polished source's DOM, classes, focus behavior, and glass role unchanged into a shared component; introduce a token only after the second page matches. Domain data stays with the page. Target order is **poor first**, then semi. ## Stay local

- Canvas empty-board hero and its readiness story (`canvas/src/lib/canvas-rail/canvas-empty-board.component.ts:203-259`): one page owns this composition.
- Chat mention/slash parsing, cursor retention and send/stop state machine (`chat/src/lib/components/molecules/chat-input/chat-input.component.ts:1068-1174,1579-1599`): extract only the repeated visual shell.
- Task palette ranking and disabled reasons (`tasks-ui/src/lib/components/palette/task-command-palette.component.ts:171-207`): one feature owns that behavior.
- Provider/model hierarchy and manual entry (`ui/src/lib/native/provider-model-picker/provider-model-picker.component.ts:162-258,356-383`): keep the domain picker intact.
- Command center scene/caption layout and marketplace catalog record layouts (`command-center/src/lib/components/command-center-page.component.ts:64-95`; inventory B:167-194): one feature each. Do not turn these into generic primitives.
