## Count method and key

Counts below are **static `class="…"` attributes in Angular inline `template:` literals and `.html` files**, excluding specs/mocks. Each matching attribute counts once per category; a class attribute can belong to multiple categories. Variants are normalized to matching utility tokens only (for example, `btn btn-ghost btn-xs`), preserving token order and size/color. This avoids treating arbitrary padding/text classes as unique variants. `rg -c` was used as a broad per-file cross-check; the template-only extraction supplies the category totals below. Angular `[class]` expressions, dynamically constructed templates, CSS, and native tags without matching classes are outside the numeric totals, so these are lower bounds on duplication. Abbreviations: C=chat, U=chat-ui, X=chat-execution-tree, K=core, M=markdown, V=canvas, T=thoth-shell, Q=command-center, N=notification-center, A=app src. Omitted library means zero matching static attributes.

## Preserve and generalize chat patterns

The existing chat look is a source for system components: `ptah-message-bubble` (`libs/frontend/chat/src/lib/components/organisms/message-bubble.component.ts:109`), `ptah-inline-agent-bubble` (`libs/frontend/chat/src/lib/components/organisms/execution/inline-agent-bubble.component.ts:75`), composers (`libs/frontend/chat/src/lib/components/organisms/subagent-lane/subagent-lane-composer.component.ts:36`; `libs/frontend/chat-ui/src/lib/molecules/lane-composer.component.ts:9`), and compact composer bar (`libs/frontend/chat-ui/src/lib/molecules/composer-compact-bar.component.ts:24`). Tool/execution card treatment should be extracted from execution nodes (`libs/frontend/chat/src/lib/components/organisms/execution/execution-node.component.ts:430`) and agent cards (`libs/frontend/chat/src/lib/components/molecules/agent-card/agent-card-header.component.ts:214`). Existing semantic badges (`libs/frontend/chat/src/lib/components/atoms/workflow-badge.component.ts:19`; `libs/frontend/chat-ui/src/lib/atoms/status-badge.component.ts:18`, `token-badge.component.ts:31`) should inform the badge API rather than be visually replaced.
