## Cross-cutting notes and decision

- **Peer range is only install compatibility.** Angular's [zoneless guide](https://angular.dev/guide/zoneless) requires notifications such as a signal read in a template, a bound listener, `AsyncPipe`, or `markForCheck`; npm peer metadata does not prove a wrapper emits those notifications. Test live input changes, resize, theme switches and tooltips in the actual zoneless webview before selecting a wrapper. Checked 2026-11-12.
- **Accessibility:** [ECharts ARIA is opt-in](https://echarts.apache.org/handbook/en/best-practices/aria/); [Chart.js leaves Canvas alternatives to the application](https://www.chartjs.org/docs/latest/general/accessibility.html); [ApexCharts claims keyboard and ARIA support](https://apexcharts.com/docs/accessibility/). Provide a short textual takeaway and accessible data table for nontrivial charts; this is an app recommendation, not a verified feature of every library. Checked 2026-11-12.
- **Theme and CSP:** resolve DaisyUI/Tailwind CSS variables at render time for Canvas; for SVG, CSS variables can style authored elements, while [ECharts highlights need special handling](https://github.com/apache/echarts/issues/19743). The stated style policy includes `'unsafe-inline'`, which addresses the [historical ApexCharts inline-style issue](https://github.com/apexcharts/apexcharts.js/issues/727); exact compatibility of any candidate with this app's full `script-src`, `worker-src`, asset URLs and VS Code webview origin is **not confirmed**. Bundle assets locally; no remote-host allowance is available. Checked 2026-11-12.
- **Maintenance evidence:** npm dates above show recent published versions. GitHub current open counts are available at [ECharts](https://api.github.com/repos/apache/echarts), [ngx-echarts](https://api.github.com/repos/xieziyu/ngx-echarts), [Chart.js](https://api.github.com/repos/chartjs/Chart.js), [ng2-charts](https://api.github.com/repos/valor-software/ng2-charts), [ApexCharts](https://api.github.com/repos/apexcharts/apexcharts.js), [ng-apexcharts](https://api.github.com/repos/apexcharts/ng-apexcharts), [ngx-charts](https://api.github.com/repos/swimlane/ngx-charts), and [D3](https://api.github.com/repos/d3/d3), but the API field includes pull requests and a single snapshot cannot establish an issue **trend: not confirmed**. Checked 2026-11-12.
- **Recommendation:** use own SVG for sparklines, meters and countdown rings. For full charts, prototype **Chart.js + ng2-charts** first for simpler charts and lower measured whole-package estimate, or **ECharts + ngx-echarts** when richer chart types and renderer choice matter. This is an inference from the cited capabilities and size estimates, contingent on an actual Angular 22 zoneless/CSP/webview probe. Avoid treating ApexCharts as MIT: its [license terms](https://apexcharts.com/license/) require an explicit business decision. Checked 2026-11-12.

## Timers/countdowns (brief)

[ngx-countdown 22.0.0](https://registry.npmjs.org/ngx-countdown) was published **2026-08-16** under MIT; npm metadata has **no peerDependencies field**, so Angular 22 compatibility is **not confirmed** from peers. Its [README](https://github.com/cipchk/ngx-countdown) shows a standalone component and `provideCountdown`; signal-native/zoneless operation is **not confirmed**. A small own service using RxJS [timer](https://rxjs.dev/api/index/function/timer) and an Angular signal read by an OnPush template ([zoneless guide](https://angular.dev/guide/zoneless)) avoids a wrapper and can derive remaining time from an absolute deadline on each tick, preserving correct display after suspend/resume or throttling. This is an implementation recommendation, not a measured performance claim. Checked 2026-11-12.
