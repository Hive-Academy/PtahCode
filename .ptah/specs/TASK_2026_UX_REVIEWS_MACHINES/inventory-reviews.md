## 4. Store state, computed values, updates

- Root injectable store holds run list, poll, repositories, list state (`loading`/`ready`/`offline`/`error`/`no-lanes`), repository/state filters, refresh timestamp, selected attempt/run, detail load state, settings/draft, token and bot identity, credential/rerun/settings/pause/refresh flags and errors. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:15-17,41-77`
- Computed `hasCache`, client-side `filteredRuns` (repo and status), `queuedCount`; no server pagination is used despite `nextCursor` in RPC response. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:78-89,95-110`; `libs/backend/review-contracts/src/lib/review-rpc.schema.ts:54-67`
- On page init `load()` and `loadSettings()` run; `load()` requests repositories and 100 runs in parallel, retains cached data and switches to `offline` on failure, or `error` without cache. `libs/frontend/review-runs-ui/src/lib/components/review-runs-page.component.ts:266-269`; `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:91-117`
- Manual `refresh()` starts one poll per enabled selected repository, reloads data, then checks per-repo `listRuns(limit:1)` poll timestamps every 1 s until changed or 120 s; it is request polling, not push streaming or a periodic page subscription. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:119-185,417-459`
- Selection immediately seeds detail with list run then fetches full run; stale detail response is ignored by attempt ID; close clears selection. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:197-226`
- Settings drafts are shallow-patched and schema-validated on save; save requires token and identity for any non-dry-run repo and sends permission attestation when set. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:314-380`
- No store `subscribe`, listener, WebSocket, or RPC push event is consumed; network activity is explicit calls in `load`, `refresh`, detail/settings/bot requests and actions. `libs/frontend/review-runs-ui/src/lib/review-runs.store.ts:91-185,208-313,327-459`
