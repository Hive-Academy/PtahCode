## 3. Diverged state

The mirror compares the live upstream hash with the sidecar's `sourceHash`. If upstream changed and the clone still equals the old hash, it fast-forwards; if both changed, it marks diverged and records the new upstream hash as pending (`libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:1850-1874`). The directory skill path uses the same rule (`:1776-1800`). An agent's upstream may be `{workspace}/.claude/agents/<slug>.md` (`libs/backend/rpc-handlers/src/lib/handlers/skill-synthesis/clone-rebase.service.ts:214-220`); plugin agents can have plugin sources (`:203-211`). **Not confirmed:** all 14 retired role files are sourced directly from `libs/backend/agent-generation/templates/agents/*.template.md` at reconcile time; the inspected mirror compares its passed source file, and the exact generation chain still needs tracing.
