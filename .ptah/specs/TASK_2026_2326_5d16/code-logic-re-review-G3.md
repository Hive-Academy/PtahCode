## Five logic questions

1. **Silent failure.** A shared selector prefix hides omitted diagnostics and leaves a success-looking roster (new defect 1).
2. **Unexpected user action.** A caller can explicitly request browser support and still lose an otherwise eligible lane if an unrelated adapter spends the remaining budget in synchronous setup (finding 1).
3. **Valid input that produces a wrong answer.** Distinct unknown exclude selectors with a common prefix produce one diagnostic with no count of the hidden entries (new defect 1).
4. **Dependency failure, timeout, or invalid response.** Rejected or malformed definitions keep legacy requirements and report the failure. Tool rejection and null preserve unknown capability, and late observed settlements classify as deadline (findings 6 and 7).
5. **Implicit case.** The compacted roster needs verification with the production token estimator, including inputs whose token density differs from the test's fixed character ratio (finding 3).
