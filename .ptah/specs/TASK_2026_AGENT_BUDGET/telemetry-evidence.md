# CLI usage telemetry evidence

Research only, against main `406c27f28`. Local probes ran once each in `captures/<cli>/` with a trivial prompt. Captures retain only numeric usage fields and event names; all other payload strings and stderr were discarded before writing. A failed or usage-free probe does **not** establish zero consumption. Cursor and Pi were not installed; Ollama Cloud GLM and Kimi Code were at plan limit, so those were not run. The captures are evidence of the observed invocation, not substitutes for adapter tests.

## Required normalization contract

Every completed model turn must yield **full input tokens** (including cached input) and output tokens, a model ID, a stable turn ID, and an evidence source. An adapter that cannot produce either total has a telemetry defect: stop the lane with `telemetry-unavailable`, retain its handoff and forbid budgeted resume until accounting is repaired. Do not count a failed probe's absent usage as zero. Optional cache read/write, last request context, and USD cost are discriminated `reported`/`unavailable` fields with a source or reason. Deduplicate per-turn and cumulative terminal snapshots. If a source reports uncached input (Claude/Grok), add its reported cache buckets to normalize full input; if cache buckets are absent, do not assert that uncached input is full input.

## Authorized account readers and cost authority

Ptah already reads account limits through `libs/backend/auth-providers/src/lib/quota/readers`: Claude `/usage` returns subscription windows (`claude-plan-usage.reader.ts:4-10,219-265`); Codex app-server quota is window percentages (`codex-plan-usage.reader.ts:69-117,137-158`); Grok billing returns credits (`grok-account-plan-usage.reader.ts:1,12-13,127-183`); OpenCode `stats --json --cost` is aggregate (`opencode-local-usage.reader.ts:19-31,58,91-99`); Antigravity combines CLI/OAuth quota (`antigravity-plan-usage.reader.ts:35-37,77-102`); Ollama's usage reader has per-model request counts (`ollama-cloud-plan-usage.reader.ts:6-23`); Kimi's reader has limit windows (`kimi-code-plan-usage.reader.ts:64-85,130-161`). **None of these readers proves per-session input/output totals.** Reuse their authorized credential path for any provider API enrichment, but do not derive a session budget from account aggregates or scrape credential files.

Cost priority: complete provider cost from the adapter or authorized usage API, then complete model-rate estimate from Ptah's OpenRouter catalog (`libs/backend/auth-providers/src/lib/providers/openrouter/openrouter-pricing.service.ts:9-13,41-62,65-90,131-146`) and bundled fallback (`libs/shared/src/lib/utils/pricing.utils.ts:56-75,242-260`). The catalog is fetched from `/api/v1/models`, cached five minutes, and times out after ten seconds; offline/unknown model returns `null`, not free. `ModelPricing` has input/output/cache-read/cache-write rates (`pricing.utils.ts:27-44`); `pricesCacheTokens` detects missing used cache rates (`:488-496`). Do not call `calculateMessageCost` without completeness checking: it substitutes zero for absent cache rates (`:461-480`). Log one bounded error per lane/model when both provider cost and complete catalog rates are unavailable; UI cost remains unknown. Derive weighted-token class ratios from the **same** resolved model rates, never Claude constants. A raw-total token floor keeps the token stop active for genuinely zero-priced or offline models, with a visible degraded coverage marker.
