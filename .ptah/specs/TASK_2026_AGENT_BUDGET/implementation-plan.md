### Weight and price decision

Claude's current weights are fixed in `libs/backend/agent-sdk/src/lib/helpers/compaction/subagent-budget-monitor.ts:244-258`. Replace these with rates from Ptah's existing `ModelPricing` (input/output/cache read/cache creation, `libs/shared/src/lib/utils/pricing.utils.ts:27-44`). `OpenRouterPricingProvider` fetches `/api/v1/models`, caches for five minutes, and times out after ten seconds (`libs/backend/auth-providers/src/lib/providers/openrouter/openrouter-pricing.service.ts:9-13,41-62,131-146,203-205`); `ensureHydrated` joins startup warmup (`:65-90`). Bundled rates cover selected models offline; unknown models return `null`, not $0 (`pricing.utils.ts:56-75,242-260`). Lane completion currently passes through adapter `costUsd` (`libs/backend/cli-agent-runtime/src/lib/cli-agents/lane-completion-outcome.ts:75-77,121-126`), and UI formats that value as `~$... est.` (`libs/frontend/chat/src/lib/components/molecules/agent-card/stats-bar.utils.ts:30-38`).

**Decision:** keep `stopWeightedTokens`, because the existing 3M setting is a token-weight limit, not USD (`advanced-settings.types.ts:177-189`). For each model, derive four class weights from catalog rates divided by a fixed, documented reference input rate; use full input/output totals as a raw-token floor so a free or offline model cannot evade the stop. When a cache split or rate is incomplete, use the conservative full-input token floor and mark price weighting degraded; never silently substitute zero. For display cost, take complete provider-reported USD first, then calculate from the same catalog with verified disjoint cache semantics and complete used-class rates (`pricing.utils.ts:461-496,620-652`). If neither source covers the lane/model, log once and display unknown. Provider plan-limit readers for Claude, Codex, Grok, OpenCode, Antigravity, Ollama Cloud, and Kimi Code expose windows, credits, or aggregate usage, not session token totals (`libs/backend/auth-providers/src/lib/quota/readers/claude-plan-usage.reader.ts:219-265`; `codex-plan-usage.reader.ts:69-117`; `grok-account-plan-usage.reader.ts:1,127-183`; `opencode-local-usage.reader.ts:58,91-99`; `antigravity-plan-usage.reader.ts:35-37`; `ollama-cloud-plan-usage.reader.ts:6-23`; `kimi-code-plan-usage.reader.ts:9,130-161`). Reuse their authorized credential path only if a provider adds a session-scoped usage endpoint.

### Lane lifecycle, warning, stop, resume

`AgentProcessManager.trackSdkHandle` receives streaming segments and installs the existing repeat-call guard (`agent-process-manager.service.ts:1455-1465`). The guard settings reader uses `agentOrchestration.laneRepeatCallStopAt` (`agent-spawn-environment.service.ts:228-248`), default 20 (`platform-core/src/file-settings-keys.ts:365-366`). Add one budget observer per tracked lane at this segment boundary, plus one lifetime timer per lane. Keep repeat-call and inactivity as independent earliest-trigger-wins guards; the latter is armed and stopped at `agent-process-manager.service.ts:2908-2970`. `maxDurationMin` measures wall time from the session's first launch across turns and resumes, whereas inactivity measures silence; a continuously active lane can hit duration. Do not reset duration on `resume_session_id`.

`sendToAgent` routes to the messaging router (`agent-process-manager.service.ts:2375-2421`); request `steer`, inspect the actual outcome mode, and record `warned` only on a delivered mode. A queued warning may arrive after the budget stop; cancel pending delivery. An `interrupt-resume` can discard partial work, so warning delivery must not choose it automatically. If no safe delivery exists, log once and still stop at the hard limit. The public `ptah_agent_stop` should continue to call the manager's ordinary `stop` (`agent-process-manager.service.ts:2654-2717`); introduce an internal `stopForBudget(agentId, reason)` that stamps `stopReason: 'budget'` **before** killing, following the existing stop race invariant at lines 2675-2688. Completion already reads `tracked.info` and signals once (`:3527-3578`); the reference includes `cliSessionId` and `stopReason` (`libs/backend/cli-agent-runtime/src/lib/wiring/agent-events.ts:676-692`). Add `budget` to `LaneStopReason` (`libs/shared/src/lib/types/agent-process.types.ts:320-325`) and its Zod message enum (`libs/shared/src/lib/types/messages/schemas.ts:136-143`), then assert that `<agent-lane-completed>` includes the true CLI session ID, not an agent-ID fallback. Current reference code can substitute `agentId` (`agent-events.ts:612,676-679`), so an unknown CLI ID must be shown as unknown and must not be advertised as resumable.

Resume enters `AgentProcessManager.gateResume` (`agent-process-manager.service.ts:686-780`), while the existing context gate can choose fresh after a large last request (`libs/backend/cli-agent-runtime/src/lib/cli-agents/lane-resume-gate.ts:292-304`). Persist budget lifetime, usage, warning state, and budget stop attribution against the CLI session ID before termination. Reconstruct on resume; refuse a stopped or >= `warnRatio` context session with a handoff path and fresh-lane advice. A fresh lane starts a new budget. If old accounting cannot be recovered, state that it is unknown, keep the elapsed time from durable `startedAt`, and do not claim a reset is safe. Handle a resumed turn's new agent ID without double counting prior usage.

## 4. Architecture and failure seams

Define one host-neutral `AgentTurnUsage` contract in `libs/shared` and require every adapter to fill it before a model turn is accepted. `inputTokens` means **full** input including cache; `outputTokens` is the turn's output. `turnId`, `modelId`, `source`, and `scope:'turn'` are required. Optional fields are explicit `reported`/`unavailable` values, never absent/zero defaults. Sketch (the implementation should narrow the source enum to actual transports):

```ts
interface UsageDatum { availability: 'reported'; value: number; source: 'stream' | 'session-file' | 'provider-api' | 'sdk'; }
interface MissingDatum { availability: 'unavailable'; reason: string; source: 'stream' | 'session-file' | 'provider-api' | 'sdk'; }
interface AgentTurnUsage {
  turnId: string; modelId: string; scope: 'turn'; source: UsageDatum['source'];
  inputTokens: number; outputTokens: number;
  cacheReadTokens: UsageDatum | MissingDatum;
  cacheWriteTokens: UsageDatum | MissingDatum;
  requestContextTokens: UsageDatum | MissingDatum;
  providerCostUsd: UsageDatum | MissingDatum;
  cacheSemantics: 'verified-subsets' | 'unknown';
}
const sourceSchema = z.enum(['stream', 'session-file', 'provider-api', 'sdk']);
const datum = z.discriminatedUnion('availability', [
  z.object({ availability: z.literal('reported'), value: z.number().finite().nonnegative(), source: sourceSchema }),
  z.object({ availability: z.literal('unavailable'), reason: z.string().min(1), source: sourceSchema }),
]);
const turnUsageSchema = z.object({
  turnId: z.string().min(1), modelId: z.string().min(1), scope: z.literal('turn'), source: sourceSchema,
  inputTokens: z.number().int().nonnegative().max(Number.MAX_SAFE_INTEGER),
  outputTokens: z.number().int().nonnegative().max(Number.MAX_SAFE_INTEGER),
  cacheReadTokens: datum, cacheWriteTokens: datum, requestContextTokens: datum,
  providerCostUsd: datum, cacheSemantics: z.enum(['verified-subsets','unknown']),
}).strict();
```

At each adapter boundary, parse the vendor payload with Zod, normalize uncached plus cache input to full input when the source proves disjoint buckets, then emit one turn record. Reconcile terminal cumulative snapshots rather than sum twice (Codex does this at `codex-lane-events.ts:177-199`; Ptah CLI computes model deltas at `ptah-cli-stream-loop.service.ts:796-827`). If required totals are absent at a completed model turn, mark `telemetry-unavailable`, stop and hand off, and refuse budgeted resume until an authorized turn ledger repairs the gap. A failed invocation before any model turn can exit normally with no fabricated usage. This fail-closed state must be distinct from `budget` and `user` stop reasons; successful turns with real zero tokens are valid only when the vendor explicitly reports both zeros. The SDK adapter translates SDK request usage (`subagent-budget-monitor.ts:209-258`) into the same accounting shape.

`AgentBudgetPolicy` accepts validated settings, turn usage, request context if reported, elapsed time, and resolved pricing. It returns warning/stop and a coverage state. `BudgetAccountingPort` persists per-CLI-session turn IDs, counters, pricing provenance, and stop metadata; `BudgetNoticePort` attempts warning delivery and returns actual messaging mode. A focused lane coordinator owns one timer and one usage observer per tracked lane, while an SDK coordinator remains in its feature lib; do not extend the large process manager with pricing logic. Resolve `ModelPricing` from the shared catalog after `OpenRouterPricingProvider.ensureHydrated()` at host startup (`openrouter-pricing.service.ts:65-90`); use the same rate object for display estimate and four weighted classes. For each model, use `max(fullInput + output, (uncachedInput×inputRate + read×readRate + write×writeRate + output×outputRate) / 0.000003)`, with USD/token rates and `uncachedInput = fullInput-read-write` only when the subsets are verified. The $3/MTok reference is fixed so catalog refresh cannot reinterpret existing counters. If cache breakdown or a used-class rate is unavailable, use the raw floor and mark price weighting degraded. Provider USD is preferred over calculated USD; neither source yields a silent zero. Persistence failure logs a real `Error`, stops the live lane and blocks unsafe resume; warning failure does not suppress hard stop. Dispose timers/listeners on stop/exit.

Wire through `libs/backend/agent-sdk/src/lib/di/registration.ts` and `libs/backend/cli-agent-runtime/src/lib/di/registration.ts` if a new injectable is needed; inspect post-merge names before writing. Electron's phased composition and CLI engine must resolve the same policy and pricing adapter. Update `container.smoke.spec.ts` and `expected-resolvable.ts` for new DI bindings; update `rpc-surface.spec.ts` and `surface-composition.spec.ts` only if RPC methods change. A shared message schema change alone should leave RPC surface names unchanged. Confirm module direction before imports; `libs/shared` cannot import either feature lib (`libs/shared/project.json:6`; `libs/backend/agent-sdk/project.json:6`; `libs/backend/cli-agent-runtime/project.json:6`).
