## Defects
1. **major — `libs/frontend/git-ui/src/lib/services/git-dock-scope.store.ts:396`: a fresh child cannot restore a pin to a closed tab.** The main store retains the pinned tab's last root when its candidate disappears, and publishes `pinnedTabId` and `repoRoot`; the child calls `showSession(pinnedTabId)`, which returns without setting a pin when `candidateForTab` is null (line 475). On detach after the pinned tab closes, the child follows the active tab, its resolved root differs from the acknowledged `repoRoot`, and the mutation gate remains blocked indefinitely. **Fix:** include the pinned fallback candidate/root in the scope contract and initialize the child pin from it, or explicitly model a closed pin in the child store.
2. **major — `libs/frontend/chat/src/lib/services/git-window/git-window-sync.service.ts:143`: a failed mode publish leaves main and child in different modes.** `applyMode` mutates the authoritative main store before awaiting `publish()` (line 147), then ignores its `false` result. `gitWindow:setMode` already returned `accepted:true` when the push to main was queued. If the publish RPC fails while the child stays open, the child keeps its previous acknowledged mode and main stays pinned or unpinned; no retry or rollback follows. **Fix:** on failed publish restore the prior main mode or retry until the child acknowledges the new host-assigned scope; expose failure to the child if the request cannot be committed.
3. **minor — `libs/frontend/chat/src/lib/components/templates/electron-shell.component.ts:527`: detaching discards the planned dock rail layout.** `detach()` sets `editorPanelVisible(false)` at `git-window-sync.service.ts:98`, so the existing dock and resize handle are removed; the separate 96-pixel rail at line 571 is rendered regardless of panel visibility. Clicking the Git tab while detached only focuses the child (line 722), so the planned hidden-to-open rail toggle and preserved dock width/resize handle never occur. **Fix:** keep the dock container mounted while detached, render the rail inside it under the existing width/resize handle, and make the tab toggle its visibility as specified.
