## New defects

**Blocking — A stop during the gate wait can reuse the captured generation.** An ordinary Continue snapshots generation `1` on a session whose old stop receipt is about to expire. While Continue waits, the latest Stop calls `advanceStopGeneration`. The read inside that call prunes the expired entry, so the fresh Stop writes generation `1` again. Recovery can see the fresh timestamp and stand down, while Continue's `1 > 1` check passes it through to activation. The spec uses a monotonically increasing mock.
