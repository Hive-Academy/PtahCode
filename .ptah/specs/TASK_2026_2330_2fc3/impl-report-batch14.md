## Decisions

- **Keep the D7 routes.** The original plan named `analyze/agents` as the selection step. D7 established the compatibility redirect to Review skills and the live `analyze/generate` page. The follow-up decision defers selection and preview, so Review skills still advances to Project guidance and existing agent-generation records keep their current routing. The route and forward action are covered in the focused onboarding specs. See `libs/frontend/onboarding/src/lib/onboarding.routes.ts:28`, `:77`, `:81` and `analyze/analyze-skills.page.ts:1332`. Reversible when a supported template source ships.
- **Keep the setup `WorkflowKind` values.** Persisted history still reads all three through `isWorkflowKind`, and the previous-sessions modal renders the resulting labels. Removing them would discard existing history labels. See `libs/frontend/chat-types/src/lib/chat-types.ts:853`, `libs/frontend/chat-state/src/lib/workflow-session-index.service.ts:34`, `workflow-session-index.service.spec.ts:49`, `libs/frontend/chat/src/lib/components/organisms/previous-sessions/previous-sessions-modal.component.ts:343` and `components/atoms/workflow-badge.component.ts:11`.

## Deferred: agent-generation start (follow-up task)

- Commit `9065bd9ae8` intentionally retired the old Choose agents and Generate agents pages. Its prior recommendations loader populated an empty selection list.
- `libs/backend/agent-generation/src/lib/services/agent-recommendation.service.ts:43` has an intentionally empty built-in agent catalog. `libs/backend/agent-generation/src/lib/services/template-storage.service.ts:49` reads the downloaded cache under `~/.ptah/templates/agents/`. This workstation has older cached templates, while `content-manifest.json:234–238` ships an empty `templates.files` list. A fresh profile has no supported template source for this flow.
- The bound generation API requires selected IDs and a confirmed preview token. See `libs/backend/rpc-handlers/src/lib/handlers/wizard-generation-rpc.handlers.ts:316` and `:486`. Once a supported template source is chosen, the proposed follow-up is a read-only template-list RPC and an `analyze/agents` selection/preview page backed by the existing preview and bound start APIs.
