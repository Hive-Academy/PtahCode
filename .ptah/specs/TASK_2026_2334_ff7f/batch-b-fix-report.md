## Terminal paths

Per-agent transient pairing state (`pendingStateBySummary` in `libs/shared/src/lib/tool-guidance/tool-call-summary.ts:34`, tracked per agent in `AgentOutputBuffer.activeSummaries` at `libs/backend/cli-agent-runtime/src/lib/cli-agents/agent-output-buffer.service.ts:38`) is released via `AgentOutputBuffer.discard(agentId)` (`agent-output-buffer.service.ts:250-262`, calling `releaseToolCallSummary(summary)` while leaving `tracked.toolCallSummary` intact for `readOutputForPersistence`) on every terminal and replacement path:

- **`completed` (exit code `0`)**: `AgentProcessManager.handleExit` (`agent-process-manager.service.ts:4190-4366`) sets `status: 'completed'` (`:4221`) and calls `this.outputBuffer.discard(agentId)` (`:4339`).
- **`failed` (non-zero exit / rejected `sdkHandle.done` / `continue()` failure)**: `AgentProcessManager.handleExit` (`:4190-4366`) sets `status: 'failed'` (`:4221`) and calls `this.outputBuffer.discard(agentId)` (`:4339`).
- **`failed` (spawn failure before handle exit)**: `AgentProcessManager.failSpawn` (`agent-process-manager.service.ts:838-860`) calls `this.outputBuffer.discard(ticket.agentId)` (`:845`).
- **`stopped` (`stop(agentId)`)**:
  - `starting` branch (`agent-process-manager.service.ts:3653-3669`): calls `this.outputBuffer.discard(agentId)` (`:3656`).
  - already-exited branch (`status !== 'running'`, `:3671-3674`): calls `this.releaseSubprocess(agentId, tracked, 'stopped')` (`:3672`), which calls `this.outputBuffer.discard(agentId)` (`:4135`).
  - `running` branch (`:3676-3722`): calls `this.outputBuffer.discard(agentId)` (`:3714`).
- **`timeout`**: `AgentProcessManager.handleTimeout` (`agent-process-manager.service.ts:3998-4020`) only emits inactivity handoff/pause notices (`asked-handoff` / `paused`) and does not terminate the lane or assign `status: 'timeout'`. When such a lane later exits, stops, expires at TTL (`scheduleCleanup` -> `releaseSubprocess(..., 'expired')` at `:4754` -> `:4135`), or disposes (`disposeAll` at `:3756,3776`), `this.outputBuffer.discard(agentId)` releases its transient state.
- **Resumed with a new `agentId`**:
  - `SystemCliLaneResumer.resume` (`system-cli-lane-resumer.ts:35`) calls `releaseIdleForResume(info.agentId)` (`agent-process-manager.service.ts:4067-4079` -> `releaseTracked` at `:4088` -> `releaseSubprocess` at `:4135`), releasing the prior agent's buffer and summary state.
  - `AgentProcessManager.trackSdkHandle` (`agent-process-manager.service.ts:1905-1911`, shared by both `doSpawnSdk` and `spawnFromSdkHandle`) checks `info.resumedFromAgentId` and calls `this.outputBuffer.discard(resumedFromId)` when the prior record is absent or non-live, covering direct `spawn({ resumeSessionId, resumedFromAgentId })` callers too.
