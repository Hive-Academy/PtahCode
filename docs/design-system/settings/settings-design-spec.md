## 1. Design direction: "Flight deck"

The settings page is where an operator configures a fleet of agents. It must feel like a calm control
room, not a marketing page and not a generic SaaS card kit.

| Axis                 | Decision                                                                                                                                                                                                                                                                                                                       | Why                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Surfaces             | Page on `base-100`. Sections sit on the page, not in cards. Cards only for items in a collection (one CLI, one connection).                                                                                                                                                                                                    | Removes the card-in-card stacks and the "plate" wrappers. Hierarchy comes from tone and space.                            |
| Color                | Gold (`primary`) only for the one primary action of a surface, the active nav item and the selected tile. Teal (`accent`) only for live and healthy signals. State colors only in `ptah-status`, `span[ptahBadge]` and `ptah-alert`.                                                                                           | One accent with one meaning. Status reads at a glance.                                                                    |
| Type                 | Inter roles from the tokens. Sentence case. No all-caps labels and no eyebrows. JetBrains Mono only for paths, model ids, ports and keys.                                                                                                                                                                                      | Fixes F10 (model value in mono).                                                                                          |
| Shape                | Pills for buttons, badges, nav items. `rounded-box` for cards. Field radius 0.625rem.                                                                                                                                                                                                                                          | Already in the theme.                                                                                                     |
| Elevation            | No shadows on sections or cards. `elevation-2` only on the sticky form-actions bar, popovers and drawers.                                                                                                                                                                                                                      | Overlays are the only things that float.                                                                                  |
| The one bold element | The instrument band (G11) under each tab header plus the nav state marks (G1 e). The band has one segment per section of the tab: a 3 px state bar, a label, a 14/20 semibold value and one meta line. A click on a segment moves focus to that section. Each nav item shows a dot and the count of items that need attention. | The page answers "what needs my attention?" before the user reads one field, and the answer is also the way to get there. |
| Gold use             | Only: one primary action per tab, the active nav item (with a 3 px gold rail), the selected tile, the field focus rail and the focus outline.                                                                                                                                                                                  | Gold keeps one meaning.                                                                                                   |
| Mono use             | Only for ids, ports, keys, paths and versions.                                                                                                                                                                                                                                                                                 | Mono marks values that the user copies.                                                                                   |
| Motion               | Keep `ptahMotionStage` tab change only. No entrance motion per section. Respect reduced motion (tokens do this).                                                                                                                                                                                                               | One deliberate moment.                                                                                                    |

Light theme (`ptah-glass-light`): the same rules with base-100 #f7f3fd, base-200 #eee8f8, base-300
#e2daf1, text #1e1936, primary #7c5700, accent #0b7f77. The F2 finding (select almost without a border
in light) is fixed by the `ptah-field` box, which has a filled background and a bottom rail.

## 2. One layout grammar

```
+--------------------------------------------------------------------------------+
| ptah-settings-layout                                                           |
| +-------------+ +------------------------------------------------------------+ |
| | [nav-header]| | header: h1 tab title, 1-line description,        [actions] | |
| |  <- Back    | | instrument band: [seg][seg][seg][seg] (bar, label, value)   | |
| |  Settings   | +------------------------------------------------------------+ |
| |             | | ptah-form-section  | aside 16rem | fields max 36rem        | |
| | > Providers | |   title, desc,     |             | ptah-field / select /   | |
| |   Context   | |   status           |             | ptah-setting-row ...    | |
| |   Advanced  | +--------------------+-------------+-------------------------+ |
| |   Search &  | | ptah-form-section ... (same two vertical lines)           | |
| |   voice     | +------------------------------------------------------------+ |
| | [nav-footer]| | collection section: full width of the content column      | |
| | Workspace   | |   ptah-toolbar + grid of ptah-surface-card                  | |
| | App         | +------------------------------------------------------------+ |
| +-------------+                                                                |
+--------------------------------------------------------------------------------+
```

Rules:

1. The shell is `ptah-settings-layout` (nav 14.5rem on `surface-1` with a hairline, content max
   52rem; the prototype changes the nav from 13rem so the longest label and its mark fit). It splits at a 768 px container
   width. At 1168 px the nav is at the left. At 784 px the nav is still at the left (784 > 768) and
   the content column is about 540 px, so `ptah-form-section` stacks (its split is 640 px).
2. Every tab starts with the layout header: title, one description line, "Checked <time>" with a
   refresh icon button, then the instrument band. The band uses one column per segment. Below a
   760 px main width it wraps (`minmax(8.5rem, 1fr)`). The nav column is 14.5rem in the prototype,
   so "Context management" fits with its mark.
   2a. State rules (from the prototype review):
   - Counts, rings, badges in a collection header and the aside status show only loaded data.
     They are hidden while the block loads or shows an error.
   - A band bar is idle (neutral) while its block loads.
   - A locked collection hides its add action. On a Free plan, "Enter a key" is the one primary action
     of the Advanced tab.
   - An invalid save keeps the edit mode, shows "Fix N field(s) before you save." in the save bar in
     the error ink, and moves focus to the first invalid field.
   - Only overlays and the sticky save bar have a shadow. The drawer opens below the app toolbar.
3. A setting group is a `ptah-form-section`. The aside holds the title, the description and an
   optional status. The fields column holds the controls. All sections of a tab use the same aside
   width, so titles align on one line and controls on a second line.
4. A collection (connections, CLI agents, output styles, web search providers, voice directions)
   is a "collection section": `ptah-section-header` plus `ptah-toolbar` when it has more than 6 items,
   then a grid or a list. It uses the full content width. It does not use the aside.
5. A view/edit value block is `ptah-editable-section` with `ptah-description-list` in view mode.
6. A boolean or a short control with a label and hint is a `ptah-setting-row` (GAP G2): label and hint
   at the left, the control at the right, optional status (for example a "Restart" badge).
7. Each async block uses the same state set through `ptah-settings-section-state` (section 5):
   loading is skeleton lines with the block height, error is a compact `ptah-alert` with one Retry
   button, empty is `ptah-state-panel` with one action.
8. A destructive or irreversible write uses `ptah-inline-confirm` (GAP G3). No raw confirm groups.
9. Feature templates set no layout spacing between sections. The layout and the patterns own it
   (`--ptah-gap-section`, `--ptah-gap-group`, `--ptah-gap-field`).
10. One primary button per surface. All other actions are secondary, outline or ghost.
11. No raw DaisyUI component classes: `btn`, `badge`, `alert`, `card`, `loading`, `skeleton`,
    `collapse`, `table`, `toggle`, `steps`.

## 3. Real "when to use" guide (supersedes the generic catalog columns)

| Need                             | Use                                                                                                                                | Do not use                                                                    |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Text, number, secret, path input | `ptah-field` + `input[ptahInput]` (unit text in the trailing slot, `revealable` for keys, `tone="mono"` for paths/ports)           | bare `ptahInput` with a separate `<label>`; `div[ptahSettingsField]` (retire) |
| Pick one of many                 | `ptah-select` when searchable or with icons. `select[ptahSelect]` inside `ptah-field` for short static lists                       | a popover of buttons for a plain choice                                       |
| Boolean                          | `input[ptahToggle]` in `ptah-setting-row` for settings that apply at once. `ptahCheckbox` for an item in a list (tools, providers) | toggle in a table cell with a duplicate state text (F5)                       |
| Status of a thing                | `ptah-status` (dot + label)                                                                                                        | a badge that repeats a control label                                          |
| Count, tier, tag                 | `span[ptahBadge]`                                                                                                                  | status words                                                                  |
| Inline problem                   | `ptah-alert` compact, with `[alertAction]` Retry                                                                                   | raw `div[role=alert]` + `btn`                                                 |
| Whole-block state                | `ptah-state-panel`                                                                                                                 | ad hoc centered text                                                          |
| Key/value facts                  | `ptah-description-list` (compact in cards)                                                                                         | stacked term-over-value blocks (F6)                                           |
| Item in a collection             | `ptah-surface-card` (spine for tone, `selectable` for choice)                                                                      | `ptah-native-card` (retire)                                                   |
| Choice among visual options      | `ptah-surface-tile`                                                                                                                | radio table                                                                   |
| Secondary detail of an item      | `ptah-native-drawer` or `ptah-native-popover` (`[keepInViewport]="true"`)                                                          | long inline paragraphs (F9); the deprecated CDK `ptah-popover`                |
| Health number                    | `ptah-ring`, `ptah-meter`, `ptah-stat`                                                                                             | big bold text                                                                 |
| Tabular data with columns        | table component from the other child (GAP G7)                                                                                      | raw `table table-xs`                                                          |
| Fold a group                     | disclosure from the other child (GAP G8)                                                                                           | raw `details/summary`                                                         |

Newer rule (user decision, 2026-11-17): for dropdowns and text field labels, the section
[User decisions after rev 2](README.md#user-decisions-after-rev-2) replaces the "Pick one of
many" row above.

### 4.2b Decision matrix (child page of Context management, new in A3)

Prototype: `screens/matrix-*.jpg`, `data-tab="matrix"`. Electron only (the matrix is Electron only now).
Nav: a nested item under Context management, indented, with a thin connector line (G1 f).
Instrument band (4 segments, decision 5): Families, Models rated, Last rating, Stale ratings.

**Decisions (parent, 2026-11-16, these replace the prototype sample columns).** Show only real data from
`agent:getCapabilityMatrix`. No invented field. No new backend field in this epic.

1. Columns: all 6 task kinds in RPC order, labels Plan, Implement, Review, Research, Tests, Docs. Bar cell,
   score 0-100, numeric value visible, tabular numbers. Unknown cell: text "Unrated", no bar, no zero. Stale
   cell: visible stale mark (not color only). Narrow width: table v2 column priority, keep Model and the
   current sort kind, other kinds go to the detail row.
2. No Speed bar.
3. Samples and rating date: per cell only, in the cell popover (source, sourceRef, asOf, note, sampleCount,
   stale). No row-level Samples column, no row-level date, no aggregation.
4. "Models rated" does not count model `*`. A `*` profile is the first row of its family group, label
   "Family default", visibly different from a model row.
5. Band segments from the RPC result: Families (distinct count), Models rated (rule 4), Last rating (latest
   `asOf` of all value cells, relative date + exact date as meta), Stale ratings (count of `stale=true`
   cells, tone warn when > 0, else ok). No routing model state.
6. Limits stay. RPC failure: `ptah-settings-section-state` error + Retry. `lastPicksUnavailable=true`: a
   visible compact note. `profiles.length === 0`: empty state. No backend task. PR description "Known
   limits": 2,000 row cap, a reader error becomes an empty local layer.
   Also: Refresh repeats the RPC, shows a busy state and announces the result. Filter, search and sort are
   client-side. Sort puts unknown cells last in both directions.
